## 👋 About Me

I'm **Hassan Nawaz**, a multidisciplinary technologist exploring the intersections of **Software Development**, **Cybersecurity & Linux**, and **E-Commerce**.

My interest in technology started with building websites and learning how digital businesses operate, but along the way I discovered something that fascinated me even more:

> **What happens beneath the surface of systems and networks?**

How do packets travel across a network?  
How do vulnerabilities happen, and how are systems defended?  
How do Linux environments power modern infrastructure?  
And how can code automate tasks while e-commerce turns ideas into real-world value?

Those questions led me toward **Kali Linux, Ubuntu, network reconnaissance, Python scripting, C++, and full-stack web fundamentals**.

I'm learning by **building, testing, analyzing, and securing**.

My current technical roadmap includes:

## 🧠 How I Learn

I don't want my GitHub to be just a collection of copied tutorials.

I use it as a place to document:

- Scripts and web projects I build from scratch
- Linux command-line workflows and system setups
- Network scanning (`Nmap`), packet analysis, and Wi-Fi security experiments
- Understanding threat vectors (such as Trojan mechanics) to build better defenses
- E-commerce storefront builds, Shopify customizations, and marketing insights
- Mistakes I make and how I troubleshoot them

Because sometimes the most useful lesson isn't:

> *"Here is how it works."*

It's:

> *"Here is what broke, how it can be exploited or fixed, and what I learned from it."*
